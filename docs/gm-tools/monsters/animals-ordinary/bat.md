# Bat
**No. Appearing:** 3d6<br>
**Armour Class:** 11<br>
**Hit Dice:** 1d4 hp<br>
**Attacks:** Bite 1d3<br>
**Nat 19:** the target suffers a random disease (*Luck* (Con) save resists).<br>
**Attributes:** S:1 D:15 C:8 I:2 P:15 W:10 Ch:4<br>
**Luck:** 4<br>
**Move:** 70 ft flying<br>

These blood drinking bats have 4 ft wing spans and drain blood to survive. After landing a hit, the bat clings on, causing 1 hp loss each round unless removed (eg: action and Str check to pry it off). Some bats also carry debilitating diseases which the host might contract, at the GM's discretion.
