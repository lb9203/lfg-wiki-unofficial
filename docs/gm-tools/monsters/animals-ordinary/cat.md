# Cat
**No. Appearing:** 1 or 2d6<br>
**Armour Class:** 13<br>
**Hit Dice:** 1d4 hp<br>
**Attacks:** Rake 1d3<br>
**Nat 19:** latches onto target's back, unable to be attacked by the target next turn.<br>
**Attributes:** S:15 D:18 C:18 I:5 P:14 W:10 Ch:8<br>
**Luck:** 6<br>
**Move:** 60 ft<br>

The cat sees as well in darkness as light, provided there is some light to amplify (eg moonlight). Advantage on stealth, climbing and balance related checks.
