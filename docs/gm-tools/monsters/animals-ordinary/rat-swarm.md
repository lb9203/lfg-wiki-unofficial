# Rat, Swarm
**No. Appearing:** 1<br>
**Armour Class:** 11<br>
**Hit Dice:** 2<br>
**Attacks:** Bites 1d6<br>
**Nat 19:** the target is overwhelmed (helpless for 1d3 rounds, *Luck* (Str or Dex) save resists).<br>
**Attributes:** S:3 D:15 C:4 I:3 P:10 W:7 Ch:4<br>
**Luck:** 5<br>
**Move:** 60 ft<br>

A rat swarm consists of hundreds of desperate, starving vermin. *Swarm* rules (p.183) apply. If threatened with fire, a rat swarm must make a Will check or be held at bay for 1d6 rounds.
