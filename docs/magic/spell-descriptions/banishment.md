# Banishment

6th Level<br>
Range: 120 ft<br>
Duration: Instant

This spell banishes a single creature from the current plane of existence. If the target is a native of the current plane, it is temporarily shunted to a

harmless pocket dimension for 1d6 x 10 minutes. If the target is a non-native to the plane (eg: most elementals and demons), it is permanently returned to its home plane. An unwilling target may make a *Luck* (Will) save to resist.
