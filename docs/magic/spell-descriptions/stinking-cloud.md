# Stinking Cloud

2nd Level<br>
Range: 120 ft<br>
Duration: 1d4 hours

As *Fog Cloud*, but any creature in the cloud must make a *Luck* (Con) save or become incapacitated with nausea and retching for 1d4 rounds, after which time the target may spend an action to make a Con check to stagger out of the cloud.
