# Feeblemind

5th Level<br>
Range: 120 ft<br>
Duration: 2d6 days

This spell causes the target to enter a largely unresponsive state, unable to meaningfully interact with the outside world without assistance. A *Luck* (Will) save resists. If the *Luck* save fails, the target's Int, Perc, Will and Cha are reduced to 2.
