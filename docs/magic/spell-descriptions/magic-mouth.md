# Magic Mouth

1st Level<br>
Range: Touch<br>
Duration: Special

This spell enchants one object with a set message. When the spell is cast, the caster decides the content of the message, the tone of delivery, and the conditions which trigger the communication. When triggered, the object forms a magical mouth and conveys the message once. The message may be up to thirty words long. The *Magic Mouth* will trigger once per level before the enchantment dissipates.
