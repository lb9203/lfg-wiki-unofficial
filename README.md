# README

[Click here to get to the wiki](https://lb9203.github.io/lfg-wiki-unofficial/)

This is an unofficial port of the Low Fantasy Gaming RPG system to
a Zensical-powered wiki for easy navigation and lookups.

Low Fantasy Gaming is a fantastic RPG system owned and distributed by [Pickpocket Press](https://lowfantasygaming.com/).
You can find their catalog at [DriveThruRPG](https://www.drivethrurpg.com/en/publisher/10564/Pickpocket-Press).
